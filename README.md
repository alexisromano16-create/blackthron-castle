# Murder at Blackthorn Castle

Install Node.js 18 or newer. In this folder, run npm start, then open http://localhost:3000.

For phones or computers on the same Wi-Fi, find the host computer's local IP address and open http://YOUR-IP:3000 on each device. Create a room, share its code, and have the host begin once four or more players join.

This local prototype cannot be played over the public internet. That is what the hosted version will add.
